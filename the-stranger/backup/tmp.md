# 审判& 审判之后 每个正常的人, 都或多或少地盼望过自己所爱的人死去

说实话, 我想起了 我亲人去世的几个场景,

1. 姥爷去世的那天晚上, 我和表哥几个聚在一起, 分享了一些快乐, 我当时在想, 这种快乐是值得羞愧的,我不应该快乐, 那时候我大概是 初中

2. 我奶奶去世的时候, 我已经特别反抗这种无意义的葬礼, 可能是因为我觉得这没有意义, 除了我们自己家里人, 又有多少人是真正地伤心难过呢? 我也撞到过 大家在我家里有说有笑打牌的老头子, 这不过是给他们提供一个聚会的场景罢了.

3. 当然, 这也给你提供了许多名号, 例如这个人很孝顺, blabla等等, 其实这是一种真实与外在割裂的表现, 你无法看清另一个人的所思所想, 因此需要一些东西来表现出来.
