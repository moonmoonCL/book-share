# 项目指引

本项目用于创作小红书《局外人》深度解析系列博文。以小说中的具体情节和人物反应为起点，结合个人阅读感受与日常经验，帮助读者理解默尔索及作品中的问题。

## 文件导航

| 路径 | 内容 |
| --- | --- |
| `局外人_gbk_utf8.txt` | 本地小说文本，供核对情节与引用；其中也包含简介、赏析等非小说正文 |
| `chapter1/final.md` | 第一篇中文稿，围绕母亲的葬礼与默尔索的反应展开 |
| `chapter1/final_en_.md` | 第一篇英文稿 |
| `chapter2345/final.md` | 第二篇中文稿，围绕爱情、友情、事业和婚姻展开 |
| `chapter6/final.md` | 海滩枪击情节的中文分析稿 |
| `backup/` | 历史备份，通常无需阅读；仅在追溯版本或恢复内容时查阅 |

目录中的数字对应所讨论的小说章节，不等同于博文篇号。以稿件内容确认范围，不仅凭文件名判断。

## 开始修改前

- 先阅读目标稿件；涉及系列衔接时，再阅读相邻篇目，了解已经提出的问题与观点。
- 根据用户要求判断是润色、补充分析还是重写。润色时保留原有立场、第一人称语气和有效的生活类比；重写时仍需让观点有文本依据。
- 用户未指定篇目且上下文无法确定时，先确认目标文件。
- 中文稿默认用简体中文。英文稿仅在任务涉及翻译或同步时修改。

## 写作风格

- 保留“我在阅读中产生疑问、回到情节寻找解释”的表达方式，避免写成教科书式概述。
- 每篇围绕一个核心问题展开，用具体情节推进分析，避免反复换说法重复同一结论。
- 适合手机阅读：段落简洁，标题明确，加粗用于关键问题与判断，不把每句话都拆成单独一段。
- 生活或游戏类比用于辅助理解，并说明类比的边界，不能用类比代替小说证据。
- 哲学概念先用日常语言解释，再说明它与当前情节的联系。避免堆砌术语、空泛升华或为了吸引点击夸大结论。
- 同一篇中文稿中的人名译法保持一致；优先沿用该稿主要使用的中文译名。

## 情节、引用与解读

- 引用与情节细节优先核对本地小说正文，不把文件中的简介或赏析当成小说原文。
- 严格区分原文直引、情节转述和个人解读。只有核对过的原句才以原文名义引用；改写内容明确作为转述。
- 不编造对白、人物心理、动作细节或因果关系。无法核实的细节删除、改为有依据的表述，或明确标注待核实。
- 对人物动机和作者意图的推断，使用“我理解为”“可能”“一种读法是”等合适表述，并给出依据；不要将推测写成确定事实。
- 允许提出有张力的解释，同时考虑与解释不符的情节。理解人物行为时，不省略行为造成的伤害与责任。
- 若引入外部评论、加缪的其他作品或哲学背景，核实来源并保留出处，不杜撰名言、页码或版本信息。

## 交付前检查

- 核对新增或改动的引用、情节顺序、人物关系与枪击等关键动作。
- 检查核心问题是否得到回应，段落之间是否存在逻辑跳跃，结论是否超出证据。
- 检查标题、人名、标点、Markdown 引用和加粗格式，清理重复表达与明显错字。
- 涉及系列衔接时，检查与前后篇是否出现未经解释的观点冲突或重复铺陈。
- 只修改本次任务涉及的文件；不顺带覆盖备份、重命名目录或同步其他语言稿件。
- 交付时简要说明修改了什么，以及仍需核实的内容。
